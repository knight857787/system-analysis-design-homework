# 源代码说明

## 怎么运行

需要 Python 3.10+（无需安装任何第三方包）。

- **Windows**：双击上级目录的 `启动系统.bat`，终端出现“访问地址”后用浏览器打开 `http://127.0.0.1:19870`；
- **命令行**：在本目录执行 `python run.py`（可通过 `--port 8080` 换端口、`--reset` 重建演示数据）。

首次启动会自动建库并灌入演示数据（约 2 MB）。
> 说明：邀请码表 `InviteCode` 由 `server/db.py` 的 `migrate()` 幂等补建（用于兼容已部署老库的升级），因此 `schema.sql` 中不重复声明。

## 目录结构

```
run.py                  启动入口（解析端口、初始化数据库、启动 HTTP 服务）
server/
  core.py               HTTP 服务、路由注册、会话与 RBAC、统一响应
  db.py                 SQLite 访问层、建库与迁移
  schema.sql            41 张表 + 4 个视图的 DDL
  seed.py               演示数据生成
  routes/*.py           13 个业务模块，共 48 个接口
web/
  index.html            SPA 外壳
  css/app.css           主题与组件样式
  js/app.js             路由、导航、登录页
  js/core.js            请求封装、表格/弹窗/提示等公共组件
  js/pages/*.js         16 个功能页（按需加载）
data/store.db           演示数据库（可删除，启动时自动重建）
```

## 与线上部署的关系

线上环境（`https://oc-emporiumretai-ms.com`）与本目录代码一致，差异只有运行参数：

| 项 | 本地 | 线上 |
|---|---|---|
| 监听 | `127.0.0.1:19870` | 同（由 Nginx 反代 443） |
| 数据目录 | `./data` | `/www/wwwroot/<域名>/data`（`STORE_DATA_DIR`） |
| 会话 Cookie | 不加 Secure | `COOKIE_SECURE=1`（HTTPS 下强制） |
| 认证 | Cookie | Cookie 或 `Authorization: Bearer`（小程序） |

部署脚本与运维手册见 `08_部署与运维/`。
